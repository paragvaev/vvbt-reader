# VVBT Reader

Небольшая статическая читалка для писем, опубликованных приложением ВВБТ. Проект не редактирует документы и не обращается к Dropbox API: он получает только публичный `publication.json` и публичные изображения.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте адрес, передав публичную Dropbox-ссылку в URL-кодированном виде:

```text
http://localhost:5173/?publication=<ENCODED_PUBLICATION_JSON_URL>
```

Если один JSON содержит несколько писем, можно дополнительно выбрать письмо по slug или ID:

```text
http://localhost:5173/?publication=<URL>&letter=<LETTER_SLUG>
```

Для публикации одного письма из ВВБТ параметр `letter` не требуется.

## Сборка и тесты

```bash
npm test
npm run build
```

Результат находится в `dist/` и подходит для любого статического HTTPS-хостинга: GitHub Pages, Cloudflare Pages, Vercel или собственного сервера.

## Tilda

Самый простой тест — разместить читалку на статическом хостинге и вставить iframe из `examples/tilda-embed.html` в HTML-блок Tilda. Для каждого письма используется собственная страница Tilda и собственная публичная ссылка `publication.json`.

Повторная публикация письма из ВВБТ с тем же slug обновляет Dropbox-файл. Страница Tilda и её настройка при этом не меняются.

## Безопасность

- В проекте нет Dropbox OAuth-токенов и секретов Tilda.
- Данные публикации считаются публичными.
- Контент вставляется через DOM `textContent`, а не как доверенный HTML.
- Поддерживаются только публичные HTTP(S)-адреса публикаций.
